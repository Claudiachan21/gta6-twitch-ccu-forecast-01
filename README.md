Forecasts GTA VI's launch-day Twitch viewers hour by hour. Log-domain k-nearest-neighbour shape transfer over the case's comparables: for each hour, the median log-ratio ln(v_h / v_1) and its spread come from the 14 comparables whose hour-1 print is closest in log space, with a 3-hour smoothing pass on the median curve. Node 22, standard library only, offline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
